# NUVRA
Nuvra — Every Coin Earned, Nothing Given


🔷 Nuvra — The Portable, Self-Updating, Deflationary Crypto Ecosystem
Nuvra is a fully decentralized cryptocurrency with a strict cap of only 10,000 coins. It redefines blockchain mining and wallet interaction by combining wallet, miner, and block explorer into a single, portable .exe application.

🚀 Highlights
Max Supply: 10,000 coins total — ever.

Mining Logic:

If a transaction is pending, it becomes the block to mine.

If no transaction exists, solo mining rewards the same as a transaction block.

Reward Delivery:

Coins are first sent to a temporary wallet, then instantly moved to your wallet—no confirmations required.

Decentralized by Design:

No central servers. Updates and releases are hosted on this GitHub repo only.

Integrated Self-Updater:

The app checks this repo for updates at launch. If a newer version exists, it offers to auto-update and safely transfers your data. The old version is removed automatically.

Deflationary Mechanics:

Every transaction has a 3% fee:

2% burned (re-mineable)

1% used as gas fee

This helps delay reaching max supply while maintaining liquidity.
